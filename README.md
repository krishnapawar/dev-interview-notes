## 🎯 Repository Standards

All documentation in this repository follows strict standards defined in [AGENTS.md](./AGENTS.md):
- **Structured Q&A Format:** Distinct Question headings (`## <Number>. <Title>`) separated from Answer headings (`### 💡 Answer`).
- **Quick Answers:** Every question includes a punchy 1–2 sentence `### 🎯 Quick Interview Answer` for rapid revision before interviews.
- **Synchronized Navigation:** Continuous numbering and GitHub-compatible Table of Contents anchors.
