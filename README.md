## 🎯 Repository Standards

All documentation in this repository strictly adheres to the format guidelines specified in [AGENTS.md](./AGENTS.md) for full compatibility with DevPrep Hub:
- **Verified Question Triggers:** Level 2/3 headings (`## <Number>. <Title>` or `### Q<Number>: <Title>`) containing question keywords for automatic recognition by the parser.
- **Interview-Ready One-Liners:** Immediate 1–2 sentence high-impact summaries formatted in blockquotes (`> **Interview-Ready Answer:**`) for rapid verbal response practice.
- **Syntax-Highlighted Code Blocks:** Every code snippet contains an explicit language identifier (`javascript`, `php`, `sql`, `bash`, `dockerfile`, etc.) for syntax highlighting and one-click copy.
- **Synchronized Navigation:** Continuous sequential numbering, GitHub-compatible anchor slugs, and verified Table of Contents.
